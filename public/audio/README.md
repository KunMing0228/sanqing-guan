# 背景音轨说明

把 **`qingjingjing.mp3`** 放进本目录，页面会自动检测并无限循环播放，UI 会显示
「《太上清静经》循环播放中」。文件路径：`public/audio/qingjingjing.mp3`。

**没有这个文件时会怎样**：自动降级为 Web Audio 实时合成的道乐氛围（低频 drone +
引磬泛音 + 木鱼 + 风声水声），界面明确标注「合成道乐 · 未检测到诵经音轨」，
不会假装已有诵经人声。浏览器禁止自动出声，必须点一次「入观」解锁音频。

## 音轨从哪来

1. **自有录音 / 有商用授权的道乐诵经录音**（推荐）。
2. **本机 TTS 合成**（本地免费、不消耗额度）。本机已有 `F:\AI\tts2\tts.bat`，
   参数形如：
   ```
   F:\AI\tts2\tts.bat --engine index --voice 解说语音v11.1 --speed 1.1 --beams 1 --text "经文分段" --out out.wav
   ffmpeg -i out.wav -codec:a libmp3lame -qscale:a 4 -ar 44100 qingjingjing.mp3
   ```
   注意：整部经约 400 字，建议按句分段生成再拼接；`.bat` 处理中文文本时可能出现
   编码问题，建议写成 UTF-8 文本文件后由脚本读入，或直接用 Python 引擎入口。
   该默认音色是「解说语音」，偏口播讲解，未必适合诵经；正式发布建议换专用诵经录音。
3. **CC0 / 明确可商用的公开道乐素材**，注意核对许可范围。

## 授权提醒

诵经录音、道乐编曲、字体、3D 模型都可能带版权。上线前请确认你有权使用，
或继续用本项目的程序化合成版本（零第三方音频依赖）。

本项目不会自动下载、抓取或引用任何第三方音频文件。


## 经文「听诵读」（与背景音乐分开）

经文面板的「▶ 听诵读」播放的是**独立诵读文件**，不是循环背景乐：

| 文件 | 内容 |
|---|---|
| `scripture/qingjingjing.mp3` | 《太上老君说常清静经》全文朗读 |
| `scripture/mantras.mp3` | 八大神咒连读 |
| `scripture/mantra_0.mp3` … `mantra_7.mp3` | 可选单篇咒语，放进去会优先播放 |

播放时背景道乐自动压低到 12%，结束恢复。没有文件时界面会如实提示，不会假装能播。

**音源口径**：网上能直链的诵经录音多为主播 / 唱片录音（版权不明）或带配乐的唱诵版，
不适合放进公开仓库；维基文库的公有领域朗读接口在本机网络下超时连不上。
因此 v1.3 改用本机 IndexTTS-2 合成：标准国语、无背景噪音、已裁静音，
全本地免费、零版权风险。若有授权清晰的正式诵经录音，直接同名覆盖即可。

重新生成：`python tools/gen_recitations.py`（需本机 `F:\AI\tts2` 环境）。
